Privacy policy

Last updated: November 8, 2026

1. Short version

This tool runs entirely in your browser. The code you paste or the files you open are processed on your device and are not uploaded, stored on a server, or shared with anyone.

2. What we collect

Nothing. There is no account, no analytics, no tracking pixels, no advertising and no cookies. We do not have a backend that could receive your data.

3. Files and code

Files you drag in or open are read locally with your browser’s File API. The fixed file you download is generated on your device. Nothing leaves it. To verify the result, your browser’s built-in JavaScript parser is asked whether the code is syntactically valid. This only parses the text; your code is never executed.

4. Local storage

The only data kept is what you opt into above: your code (if “Remember my code” is on) and that setting itself. It lives only in this browser and you can delete it at any time with the button above or by clearing your site data.

5. Third-party resources

The page loads its styling from the Tailwind CSS CDN (cdn.tailwindcss.com). Like any web resource, that request exposes your IP address and browser details to the CDN provider. Your code is never part of that request. To avoid it entirely, self-host the stylesheet.

6. Your control

You decide what is remembered. Turning the setting off, deleting stored data or clearing site data removes everything this tool has saved.

7. Changes

If this policy changes, the updated version and date will appear here.
